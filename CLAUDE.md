# PocketList: правила дизайна и работы

Сайт: https://pocketlist.ae. Маркетплейс аренды жилья в Дубае, объявления напрямую от владельцев.
Стек: Next.js (Turbopack), Tailwind v4, shadcn/ui, Geist.
Язык интерфейса: английский (есть переключатель языков). Общение со мной по-русски.

## Цель текущего апгрейда
Убрать признаки «сделано ИИ»: дефолтные токены, дефолтные тени и кривые, иконки везде, безликий копирайт, отсутствие бренда. Полный список проблем в `docs/REVIEW.md`.

## Жёсткие правила (нарушение = задача не выполнена)

### Токены и бренд
- Токены shadcn по умолчанию оставлять нельзя. Сначала выбирается один акцентный цвет, потом переопределяются `--primary`, `--ring`, `--radius`, тени.
- Неиспользуемые токены (`--sidebar-*`, `--chart-*`) удалить или реально использовать.
- Палитра Airbnb (`#222 / #6a6a6a / #ebebeb`) не должна остаться как есть. Нужна своя тёплая или холодная нейтраль.
- Нужен знак логотипа, а не только слово «PocketList» в Geist Bold. Сжатое состояние шапки («PL») должно быть спроектировано, а не обрезкой.

### Движение (по скиллу apple-design)
- Запрещено: `transition: all`, голые `cubic-bezier(0.4,0,0.2,1)` на всём подряд, Tailwind-тени `shadow-md/lg/xl` без правки.
- Всё, что пользователь трогает (сердце, карточки, меню, галерея), делаем на пружинах (Motion). Базово: damping 1.0 (bounce 0), bounce 0.2 только после жеста с импульсом.
- Перелёт (overshoot) у статичного бейджа (`badge-pop`) убрать.
- Реакция на нажатие: на pointer-down, не на отпускание. Кнопка `:active` даёт `scale(0.97)`.
- Анимируем только `transform` и `opacity`.
- Обязательно поддерживать `prefers-reduced-motion` (уже есть, не сломать) и `prefers-reduced-transparency`.
- Типографика: заголовки с отрицательным tracking, мелкий текст около 0 или слегка положительный, line-height обратно пропорционален размеру.

### Иконки и UI
- Иконка только если она заменяет слово или ускоряет сканирование. Иконка на каждом пункте меню не нужна.
- Один переключатель языка, а не три.
- Фича «Unpin header» удаляется, если нет явной причины её оставить.
- Иерархия действий на листинге: `Show Contact` главное, остальное вторично, не четыре равных кнопки.

### Копирайт
- Без em-dash (—) в заголовках и тексте интерфейса. Использовать «|» или «·».
- Без цепочек коротких параллельных фраз («No X. No Y. Just Z.») и без «There's no password.»-ритма.
- Конкретика вместо общих слов. Hero говорит, что делает продукт, и ведёт к действию («Post your home»).
- Кнопки без стрелок-глифов в тексте (`Send code →`), стрелка только как отдельная иконка, если нужна.

### Данные
- Площадь округлять: `759.29 sqft` → `759 sqft`.
- Значение не повторяет название поля: `Furnished: Furnished` → `Furnished: Yes` или скрыть строку; `Parking: Spots: 1` → `Parking: 1 space`.
- Для Дубая показывать то, что ждут арендаторы: цена в год и в месяц, количество чеков, Ejari. Номер Trakheesi/RERA не собираем и не показываем: объявления подают сами владельцы (решение от 2026-11-06, коммит 8b37e7d).

### Мета и доверие
- Добавить `og:title`, `og:description`, `og:image`, `twitter:card`.
- Уникальный `<title>` на каждой странице (на `/login` сейчас такой же, как на главной).
- Футер: Terms, Privacy, About, Contact. Гид просит Emirates ID, без юридических страниц это недопустимо.
- Описание в meta должно совпадать с тем, что есть в интерфейсе (на главной нет призыва выложить объект).

## Процесс работы

1. Всегда начинай с plan mode. Код не пиши, пока я не одобрил план.
2. Работа идёт отдельными коммитами в порядке: токены/бренд → движение → контент и данные → листинг → мета и футер. Один коммит = один этап, чтобы любой можно было откатить.
3. После каждого этапа: скриншоты в 1440px и 390px для главной, листинга, `/guide`, `/login`. Без мобильного скриншота этап не закрыт.
4. После каждого этапа запускай агента `design-critic` (он видит только скриншоты и этот файл) и исправляй найденное.
5. Тестовые листинги («Test Home N», цветные плитки с цифрой) в оценке дизайна не участвуют. Для оценки карточек используй реальные объекты или добавь реалистичные фикстуры с настоящими фото.
6. Не меняй логику авторизации, оплаты и контрактов, если задача про дизайн.
7. Перед завершением: линтер, типы, сборка (`npm run build`) без ошибок.

## Команды проекта

- `/audit`: ревью экранов по этому файлу, приоритетный список.
- `/tokens`: этап 1, токены и бренд.
- `/motion`: этап 2, движение.
- `/copy`: этап 3, копирайт и данные.
- `/listing`: этап 4, страница листинга.
- `/meta`: этап 5, мета, футер, доверие.

## Чего не делать

- Не добавлять градиенты, glassmorphism, эмодзи в интерфейс и свечения без причины.
- Не копировать чужой сайт дословно (особенно Airbnb).
- Не заявлять «готово» без скриншотов.
