# Промпты для Claude Code

Запускай по порядку. Каждый этап отдельный коммит. Перед каждым: `/clear`.

## 0. Старт (plan mode, Shift+Tab)

```
Прочитай CLAUDE.md и docs/REVIEW.md. Войди в plan mode. Задача: убрать признаки
ИИ-генерации с pocketlist.ae. Составь план по коммитам: токены, движение, контент
и данные, листинг, мета и футер. Для каждого коммита назови файлы, которые
будешь менять, и как проверишь результат скриншотами в 1440px и 390px.
Код пока не меняй.
```

## Контроль качества (после любого этапа)

```
/audit
```

```
Запусти агента design-critic. Передай ему только скриншоты (1440px и 390px:
главная, листинг, /guide, /login) и CLAUDE.md. Исправь всё из раздела
«Критичное» и «Важное», затем повтори скриншоты.
```

## Полезные одноразовые промпты

Реальные данные вместо заглушек:

```
Добавь в dev-базу 8 реалистичных листингов с настоящими пропорциями фото
(3:4 и 4:3), разными районами Дубая и разной длиной названий. Помечай их
флагом fixture, чтобы удалить одной командой.
```

Тёмная тема:

```
Проверь тёмную тему на всех экранах: контраст WCAG AA, тени, границы, фото
и плейсхолдеры. Дай скриншоты до и после правок.
```

Мобильная версия:

```
Прогони главную, листинг, /guide и /login в 390px и 768px. Найди горизонтальный
скролл, мелкие тап-зоны (меньше 44px), обрезанный текст, налезающие элементы.
Исправь и покажи скриншоты.
```

Финальный заход:

```
Сделай финальную проверку: npm run build без ошибок, линтер и типы чистые,
скриншоты всех экранов в 1440px и 390px, список оставшихся замечаний
design-critic. Не заявляй «готово», пока не приложишь скриншоты.
```
