# Ревью pocketlist.ae: признаки «сделано ИИ»

Дата: 2026-11-07. Просмотрено: главная, страница реального листинга, /guide, /login, CSS-токены, keyframes. Тестовые листинги исключены.

Не проверено: мобильная версия (окно браузера не уменьшилось до 390px), тёмная тема, /admin, /profile, ступенчатость появления карточек.

## Сильные признаки

1. **Токены shadcn/ui без изменений.** В `:root` полный стандартный набор: `--card`, `--popover`, `--muted`, `--chart-1…5`, `--sidebar-*`, `--radius: .625rem`. Sidebar и charts не используются.
2. **Нет бренда.** Серый фон `#f7f7f7`, текст `#222`, чёрные кнопки, Geist (дефолт Vercel). Логотип это слово «PocketList». Акцентного цвета нет.
3. **Дефолты Tailwind.** Тень поиска = `shadow-lg`, у кнопок `0.15s cubic-bezier(0.4,0,0.2,1)`, у карточек `transition: all`, ховер картинки `scale-[1.03]` за 0.3s.
4. **Иконка lucide на каждом пункте меню.** Всего 32 SVG.
5. **Страница входа:** точечный halftone-фон с радиальной маской, центральная карточка, «Send code →» со стрелкой в тексте, плейсхолдер `you@example.com`.
6. **Ритм копирайта:** «Every step, from the first visit to a signed contract.», «You don't need an account for this.», «There's no password.» Hero «Dubai Properties» безликий.

## Средние признаки

- `badge-pop` (scale 0→1.2→1 с blur) и `heart-pop` (1→1.45→0.9→1) сделаны keyframes; их нельзя прервать посреди движения, перелёт на статичном бейдже не оправдан. Есть `card-in` (fade + сдвиг 10px). `prefers-reduced-motion` поддержан.
- Переключатель языка в трёх местах (меню, страница, футер). Лишняя фича «Unpin header».
- Em-dash в заголовках (`PocketList — Dubai Real Estate`, `Guide — PocketList`).
- Таблица характеристик ровными строками без иерархии; четыре равноправных действия в контактной карточке.
- Палитра `#222 / #6a6a6a / #ebebeb` совпадает с Airbnb.

## Баги и недоработки данных

- Шапка при скролле на листинге: логотип сжимается в «PL», на одном кадре виден обрезанный «Pock Li».
- «759.29 sqft» (неокруглённое значение после конвертации).
- «Furnished: Furnished», «Parking: Spots: 1», «Floor: Middle floor».
- Meta description обещает «Post your own home with photos in minutes», на главной нет призыва выложить объект.
- Нет `og:` и `twitter:` тегов. Title на /login такой же, как на главной.
- Футер без Terms, Privacy, About, при этом гид просит Emirates ID или паспорт.

## Приоритет исправлений

1. Бренд и токены: акцент, radius, тени, нейтрали, логотип.
2. Движение: пружины, убрать `transition: all`, убрать перелёт у бейджа, починить шапку.
3. Копирайт и данные.
4. Страница листинга: иерархия, группировка, цена, галерея.
5. Мета и юридический футер.
